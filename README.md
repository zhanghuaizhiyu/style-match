# style-match

> WorkBuddy 技能：图片风格分析与迁移（Style DNA → 风格匹配 → 逐元素迁移）

把任意图片的视觉风格提炼成一份可复用的「风格档案」，支持单图分析、多图共性归纳，并把分析归纳出的风格逐元素迁移到其他照片上。

## 功能

| 模式 | 说明 |
|---|---|
| **A 单图分析** | 提取元素风格，量化冷暖色占比（暖 X% / 冷 Y% / 中性 Z% + 主色 hex），氛围标签，简约-繁华度 1~10 评分 |
| **A+ 元素识别** | 穷举画面内容元素并区分（公路、天空、云朵、海洋、汽车……），按层次归类，附每元素风格速写 |
| **B 多图归纳** | 逐图建档后求交集，输出共性风格档案 + 各图差异说明；风格冲突过大时如实报告分歧 |
| **C 风格迁移** | 默认**逐元素对应迁移**：参考图天空→目标图天空、海→海、岩壁→岩壁、生物→生物，逐元素提取风格DNA、逐元素写提示词、逐元素校验 |
| **C+ 元素级迁移** | 只把参考图中某一元素的风格迁移到目标图对应元素，其余元素锁死不动 |

### 迁移核心规则

- **元素映射表**：迁移前建立参考图 ↔ 目标图的元素映射，交付时附映射表和对齐情况
- **简约度贴合**：按档案的简约-繁华评分控制细节量，删除主要轮廓以外的细碎线条
- **删细碎 ≠ 抹平结构**：主体保留可读的体块结构（层理、棱面、明暗阴影面），避免空洞失真

## 安装

将本仓库的 `style-match/` 文件夹复制到 WorkBuddy 的技能目录：

```
C:\Users\<用户名>\.workbuddy\skills\style-match\
```

目录结构：

```
style-match/
├── SKILL.md            # 技能主文件（触发描述 + 工作流程）
└── agents/
    └── interface.yaml  # 技能接口元信息
```

重启 WorkBuddy 或新开会话即可生效。无需安装依赖、无需 API Key（生图使用 WorkBuddy 内置 ImageGen 能力）。

## 触发方式

发图后说：

- "分析这张图的风格 / 冷暖色调 / 氛围 / 简约还是繁华"
- "看看这几张图有什么共同风格"
- "把这几张图的风格套到这张照片上"
- "识别这张图有哪些元素"
- "把参考图的『岩壁』风格迁移到目标图"

或直接 `@style-match`。

## 使用示例

1. 发 8 张同风格参考图 + 1 张目标照片 → 输出共性风格档案 + 逐元素迁移结果
2. 发 1 张海滨公路照片问"有哪些元素" → 输出：公路、天空、云朵、太阳、海洋、汽车（分层归类 + 风格速写）
3. 发神庙油画图 + 峡谷照片，说"把岩壁风格迁过去" → 只有岩壁被转绘，其余元素不变

## 与 image-style-fusion 的分工

- `image-style-fusion`：两张图直接合成（图一风格 → 图二图案），快，但不产出量化档案、不支持多图归纳
- `style-match`：先分析量化、可归纳多图共性、档案可留存复用、支持逐元素迁移
